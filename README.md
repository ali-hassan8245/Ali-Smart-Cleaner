# 🧹 Ali Smart Cleaner

A lightweight and fast Windows system cleaning tool built using Batch scripting.  
It helps remove temporary files, cache, and junk data to improve system performance.

---

## ✨ Features

- ⚡ Normal Clean (Fast & Safe)
- 🔥 Deep Clean (Advanced Junk Removal)
- 🎯 Selective Cleaning Options
- 💾 Disk Space Viewer
- 📜 Activity Logging System
- 🔍 Fake System Scan UI (for better UX)
- 🧼 Safe cleanup (no personal files affected)

## 🚀 How to Use

1. Download or clone the repo
2. Run `cleaner.bat`
3. Choose an option from menu
4. Done ✔

> ⚠ Always run as Administrator for full functionality

---

## 🛠 Requirements

- Windows OS
- Administrator access
